The total, disjoint ISA is implemented with mandatory exactly-one subtype pointers and deferred composite foreign keys; each subtype has its own autogenerated Id and UNIQUE VehicleActivityId. Awards similarly require an owned first component, preserving the 1..N benefit minimum.

## Full dictionary

Every relation has Id INTEGER PRIMARY KEY AUTOINCREMENT. CK columns are NOT NULL + UNIQUE. FK enforcement is enabled on each connection; deletes do not cascade. ? marks nullable. Intervals are half-open [start,end), with NULL end meaning unbounded.
